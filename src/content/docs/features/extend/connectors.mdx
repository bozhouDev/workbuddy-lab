聊到连接器，网上经常冒出一个英文缩写 **MCP**（Model Context Protocol，模型上下文协议）。用生活里的东西一类比你秒懂：

以前手机、相机、耳机各有各的充电口；后来统一成了 **Type-C**，一根线什么设备都能连。**MCP 就是 AI 世界的「通用 Type-C 接口」**——让 AI 能在你授权的前提下，直接去查飞书消息、读腾讯文档、写表格、建日程。

而 WorkBuddy 里的 **连接器**，就是官方把常用 MCP 工具打包好了。**不用你敲一行代码，点几下扫码授权就能直接用。**

## 以「飞书」为例：从接入到跑通

### 第 1 步：安装并扫码认证飞书连接器

1. 点左侧栏 **专家·技能·连接器** → 切到 **连接器**；
2. 找到 **飞书**，点右上角的 `+` 安装，装完后卡片上会出现一个绿色的 **已连接** 小圆点；
3. **完成账号认证**：不用到处找设置页，**直接回到对话框里跟它说一句“帮我认证飞书”**，它会在对话里给你弹出一个二维码，用手机飞书扫一下确认授权就通了。

### 第 2 步：先拿一个小任务「验货」

扫码认证完，先发一句最安全、只读的小任务，确认通道真的通了：

```text
用飞书连接器，帮我查一下我最近更新的 5 篇飞书文档名称。只列标题和更新时间，不要修改任何文档。
```

能正常返回你飞书里的文档名，就可以放心用起来了。

### 第 3 步：真实案例——用飞书多维表格记商单和月底对账

记住一个原则：**接上连接器不等于它会自动知道你要改哪张表**。每次调用连接器，把 **5 件事说清：用哪个服务 + 找哪张表/文档 + 时间范围 + 做什么动作 + 结果放哪**。

**场景 1：随口丢一句话，让它帮你记进飞书多维表格**

```text
请用飞书连接器，在我的《2026商单与账目表》多维表格里新增一条记录：
- 合作方/项目：XX 咖啡新品推广
- 类型：商单收入
- 金额：6000 元
- 当前状态：已确认排期，待交初稿
- 预计结款日：下周五

写入前先给我看一眼要填入的字段预览，我确认后再提交，不要改动表格里已有的其他记录。
```

**场景 2：月底一键对账、查哪些款还没回**

```text
请用飞书连接器，读取《2026商单与账目表》本月的所有记录：
1. 统计本月已收款总额、待结款总额、各项支出合计和净收入；
2. 单独把「已交付但未回款」的商单列成一张催款清单；
3. 结果整理成一份《本月对账汇总.md》保存到当前分组文件夹；
4. 只读取统计，不要修改或删除飞书原表里的任何数据。
```

<Warning title="用连接器的两条保命红线">
  <ol>
    <li><strong>第一次只做小范围只读测试</strong>（比如只查最近 5 篇文档、先拿一张测试表试写），跑顺了再放开范围。</li>
    <li><strong>凡是涉及「删除记录/文档」「往群里发消息」「对外发邮件」这类收不回来的动作</strong>，必须在提示词里写死一句：<strong>「执行前先列清单跟我确认，不要动其他内容」</strong>。</li>
  </ol>
</Warning>

### 第 4 步：看清授权了什么，不用就解除

点开已连接的飞书卡片，详情里有一栏 **可用功能**，就是它能替你做的事，比如读文档、创建文档、往多维表格里录数据。授权给了它什么，它就真能做什么；**发消息这类发出去收不回来的动作**，用之前要让它先列清单给你确认。不再用的连接器，在详情里点 **解除授权**。

还要知道：它能读多少，取决于你授权的账号和勾选的权限，可能包括同事共享给你的文档。所以每次都要说清范围，不然它会把不相干的资料一起翻进来。

除了飞书，列表里的腾讯文档、腾讯会议、QQ 邮箱、金山文档/WPS 云文档、钉钉等连接器用法也完全一样。列表里没有的服务，可以用右上角「自定义连接器」自己接，见下一篇 [自定义连接器：做一个自己的 MCP](/features/extend/custom-connector/)。

## 一句话记住

**连接器接上后先用只读小任务验货；每次用说清服务、目标表、范围和动作，删除或外发前必须先确认。**
