你最近在网上大概率经常刷到“给 AI 装几个 Skill 效率翻十倍”，听着挺玄乎，其实它的本质特别简单——**Skill 就是一份打包好的「标准操作手册（SOP）」**。

## 装和不装 Skill 差在哪

- **不装 Skill 时**：你每次让它做 PPT 或处理复杂表格，都得自己反复写要求——字号多大、颜色怎么配、先干哪步再干哪步、哪些坑别踩。少说一句，它就发挥失常。
- **装了 Skill 之后**：有人已经把这类活最成熟的一套步骤、规范模板、甚至配套小脚本全写进一个包里（核心通常就是一个叫 `SKILL.md` 的说明书）。AI 执行任务前先翻开这本手册，照着里面的规矩一步步做，**不用你每次重教，出品稳得多**。

## 怎么找、怎么装

装技能主要有三种方式，都很省事：

1. **直接在「技能」广场一键装**：进左侧 `专家·技能·连接器` → 切到 **技能**，右上角直接搜关键词（比如 `PPT`、`PDF`、`CloudBase`），看到合适的点卡片上的 `+` 就装好了。
2. **逛腾讯的 SkillHub 市场按下载量挑**：在技能页里切到 **SkillHub**（腾讯官方的 Skill 市场，对应 `skillhub.cn`），里面聚合了大量优质 Skill。新手不知道哪些好用时，直接按 **下载量** 或分类筛一遍，挑大家用得最多、最稳的装，很少踩雷。
3. **发链接让它自己装（进阶好用）**：如果你在 GitHub 或别人文章里看到好用的开源 Skill，不用懂代码，直接点右上角 `+ 添加技能`，或者干脆在对话框里把地址发给 WorkBuddy，说一句：

```text
帮我安装这个技能：[贴上 GitHub 链接]
```

它会自动拉下来帮你装好。

## 装完怎么调用

有两种顺手的叫法：

- **在输入框里直接打 `/`**，会立刻弹出你已经装好的所有技能列表，点选一下就行（也可以点 `+` → **技能** 选择）；
- **直接说大白话**：比如在任务里写一句“用 XX 技能帮我生成这份 PPT”，它自己也会识别并调用。

## 一句话记住

**Skill 是 AI 的岗位操作手册；用到什么去技能广场或 SkillHub 装什么，干活时打 `/` 一键调用。**
