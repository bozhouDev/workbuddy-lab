通用模型什么都懂一点，但默认什么都不算最精。WorkBuddy 提前按行业和岗位配好了一批 **专家**，相当于公司里现成的专业同事，不用你每次自己写长长的人设去调教。

如果一个大活需要多个岗位配合（比如既要产品经理拆需求、又要设计师定风格、还要工程师写代码），还可以直接请 **专家团** 分工干。

## 怎么找、怎么召唤

1. 点左侧栏的 **专家·技能·连接器**，默认就能看到 **专家** 列表，可以按行业分类逛，也可以直接搜关键词。
2. 看到合适的点一下「召唤」（或立即使用），对话框就会直接切到这位专家的状态；平时在首页输入框里，也可以点左下角 `+` → **专家** 随时召唤。

## 新手最值得先试的几个起步专家

- **PPT制作专家 / PPT视觉美化师**：从零做汇报、或者把现有丑 PPT 重构美化都特别省事；
- **数据分析专家**：丢进去几张 Excel，它比默认状态更会找业务异常和关键指标；
- **微信小程序开发专家**：后面实战做小程序时直接用得上。

## 一句话记住

**遇到专业活别硬靠裸聊，先从「专家·技能·连接器」或输入框 `+ → 专家` 请对应岗位上场。**
