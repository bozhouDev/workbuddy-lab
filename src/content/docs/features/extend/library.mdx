用了一阵子你可能会发现：有些东西（比如公司介绍、常用行业报告、你的写作风格样本、或者 AI 刚刚生成的一张好图）在好几个项目里都要反复用到。如果全散在不同分组的文件夹里，每次还得满硬盘翻。

点左侧栏的 **资料库**，就是专门用来统一放这些“长期反复用的资产”的。里面分得很清楚：**新建、最近、本地产物、我的资料、团队空间**，支持 Markdown、CSV、HTML 等常见格式。

## 资料库平时怎么配合着用

- **往里放**：平时反复要用的参考文档直接传进资料库；你用 WorkBuddy 生成的图片、视频和满意的成品，也可以顺手收进资料库里存着。
- **往外用**：发任务时，点输入框左下角 `+` → **添加文件 → 资料库**（如果连了腾讯文档、ima、乐享知识库，在同一个菜单里也能直接选），直接喂给当前任务当参考。

## 建个人资料库的 4 条实在经验

很多人一听说“搭建个人 AI 知识库”，兴冲冲把微信收藏夹、网盘里吃灰三年的 500 篇文章一股脑全倒进去——结果 AI 检索时翻出一堆过期废料，回答反而越找越偏。

记住 4 条就行，少走弯路：

1. **先建 3 个分类就够**：`学习资料`（存好文章和笔记）、`当前项目`（存正在干的活）、`成果输出`（存你满意的成品），别上来搞十几层大体系。
2. **用到什么放什么，先拿 3–5 份跑通**：先挑几份你这周真要用的资料放进去，验证它能读准、能用上，再慢慢往里添。
3. **定期清理**：吃灰和过时的资料每隔一两周删一删，库越干净，AI 找得越准。
4. **隐私机密别往云端扔**：账号密码、个人证件、公司核心机密文件，留在本地加密存好，别随便同步进云端知识库。

## 特别好用的玩法：让它建一份「目录索引」

资料一多，你自己都忘了库里存过啥。挑一个分类，发下面这段话让它给你盘一遍家底：

```text
请读取我选中的资料库文件，按主题帮我整理一份《资料库索引清单.md》保存到当前分组：
1. 每份资料写清：标题、三句话摘要、核心观点、适合用在什么场景；
2. 每条后面标出对应的原文件名；
3. 如果某份文件打不开或读不到内容，直接列出文件名，不要猜测；
4. 只读取整理，不要修改、移动或删除任何原始资料。
```

有了这份清单，你再也不用一篇篇点开翻，直接看目录就知道哪份资料能拿来用。

## 一句话记住

**资料库先建 3 个分类、用到什么放什么，别把吃灰收藏一股脑全塞进去，隐私机密不放云端。**
