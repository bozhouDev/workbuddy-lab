**一个「分组」就是一个项目，背后对应你电脑里的本地文件夹**。你把相关资料放进去，WorkBuddy 干活时去这里读，生成的成品也存在这里。

## 为什么要专门建分组

如果你懒得选分组就直接发任务，WorkBuddy 会把东西存到默认工作空间的临时目录里。跑一两个任务看不出问题，跑完二十个任务，你想找上周改好的那份表，翻半天都不知道落哪去了。

反过来，**一件事建一个分组**：材料和产物都在一块，下次接着改直接进这个分组开新对话，好找、不容易串味，也能减少误操作。

## 推荐的文件夹目录结构

不用搞得很复杂，在你刚才定好的存储目录下，照着下面分 5 个大目录就够用很久了：

```text
WorkBuddy-工作区/
├── 00_临时/      # 随便试新功能、跑一次性的小活，定期清理
├── 01_任务/      # 正在处理的零散小任务（比如整理一份纪要）
├── 02_项目/      # 稍微大点的事，每个项目单独建一个子文件夹
├── 03_知识库/    # 长期要反复参考的资料
└── 99_归档/      # 已经做完、留着备查的成品
```

## 怎么把文件夹加进分组

1. 在电脑里先建好一个干净的练手文件夹（比如放在 `00_临时` 里的 `WorkBuddy-练习`）。
2. 回到 WorkBuddy 首页，点输入框左下角的 **选择分组**，选 **新建分组** 或 **选择本地文件夹**，把刚才那个目录关联进来。
3. 关联完之后，左侧边栏的「分组」里就能看到它了。

## 两条保命提醒

<Warning title="开始前先看这两条">
  <ol>
    <li><strong>千万别一上来就把「桌面」「下载」或者存满重要资料的文件夹设成工作目录</strong>。你让它“帮我整理一下没用的文件”，它可能顺手把你桌面别的文件一起挪了甚至删了。</li>
    <li><strong>重要原件先复制一份副本</strong>放进练习文件夹，原件留在别处备份，怎么折腾都心安。</li>
  </ol>
</Warning>

## 一句话记住

**一件事建一个分组；先建干净的练习目录、只放文件副本，绝不把桌面直接设为工作目录。**
