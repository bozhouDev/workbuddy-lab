## 重点看这 5 项设置

| 设置项 | 建议怎么设 | 为什么要这么设 |
|---|---|---|
| **允许锁屏运行** | **按需开**（平时保持关闭） | 打算出门用手机遥控电脑干活，才需要开启锁屏后继续运行；只在电脑前用就先关着。旁边 **运行时防止系统休眠** 默认开着，保持开启就行，防止跑长任务时电脑自己睡着 |
| **技能自动更新** | **打开**（默认已开） | 后面装的各种 Skill（技能）会持续更新修 bug，开自动更新省得手动一个个点；而且它不会覆盖你自己编辑过的技能 |
| **默认工作空间存储路径** | 改到自己熟悉的位置，**Windows 别放 C 盘** | 新建任务、分组默认都会存在这下面，用久了文档、表格、项目文件越积越多，放系统盘容易撑爆，单独建个目录也方便找和清理 |
| **桌面通知** | **打开**（点「前往系统设置」授权） | 复杂任务常要跑一两分钟，开通知后你可以切去干别的，它干完会弹窗提醒你回来验收，不用干瞪眼 |
| **隐私（最下方）** | **看清说明，自己决定** | 往下滑到底部是隐私设置，主要涉及是否回传体验数据。平时要处理公司或个人敏感材料的，介意的话按需关掉即可 |

<Warning title="提前避个坑：Windows 第一天就挪出 C 盘">
  Windows 用户最容易偷懒不改默认存储路径，等用上两个月、跑了几个网页和数据分析项目，突然发现 C 盘红了，回头再挪路径反而麻烦。第一天就点「更改」挪到非系统盘最省事。
</Warning>

## 一句话记住

**存储路径挪出系统盘、打开桌面通知和技能自动更新、锁屏运行按需开启。**
