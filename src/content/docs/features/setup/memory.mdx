用过一段时间 AI 的人基本都遇到过这事：昨天你反复交代好“表格第一列放日期、别写一堆废话”，它改对了；结果今天新开一个对话，它像换了个陌生人一样，老毛病又全犯一遍。

AI 默认是不跨对话记事的。点左下角头像 → **记忆与进化**（或者在设置左侧直接点「记忆与进化」），就能看到 WorkBuddy 的自动记忆开关。

## 两个开关都建议打开

- **云端记忆**：自动记住你平时对话里的关键信息，每晚会自动整理更新，让后面的回答越来越贴合你。以前在别的 AI 工具里攒过记忆的，也可以点右侧 **导入** 直接带进来。
- **本地记忆与技能**：专门记录有长期价值的项目成果和约定（既支持全局用户级，也支持单个项目级），让它在后续任务里继续遵循。

## 用好记忆的两个习惯

1. **可以主动让它记**：平时对话里发现它改对了，直接补一句就行，比如：

```text
记住这条：只要有我让你反复修改的地方，记住正确的改法，以后别再犯同样的错。
```

2. **记得定期翻一眼，把「记歪的」删掉**：自动整理的记忆是全局共享的，偶尔会记偏。比如你某天临时帮朋友写了一封英文邮件，它可能误以为你以后都偏好英文输出。哪天发现它突然莫名其妙跑偏，第一反应就是打开「管理云端记忆」翻一遍，**过时的、一次性的、记错的，直接删掉或改掉**。

## 一句话记住

**记忆要开，改对了好方法要主动让它记；但发现回答突然跑偏时，第一时间去云端记忆里删掉记歪的条目。**
