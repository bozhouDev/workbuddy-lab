## 1. 看懂模型、倍率和标签

模型就是 WorkBuddy 的大脑，不同模型擅长不一样，消耗的积分也不一样：

- **后面的数字就是积分倍率**：数字越大，跑同一个任务扣的积分越多（比如 `0.15x` 比 `1.00x` 便宜得多）。
- **小白最省心的选法**：不用背每个模型叫什么，直接用最上面的自动档——**快速（0.15x）/ 均衡（0.50x）/ 极致（1.00x）**，让系统自己按任务挑模型。
- **留意绿色和橙色小标签**：像图里 `Hy4 flash` 标着 **限时免费（0.00x）**，平时练手、问简单问题可以直接用；部分模型标着 **夜间折扣**（晚上用更省积分）或 **订阅优先**。

<Warning title="别踩烧积分的坑">
  拿 <code>1.00x</code> 的极致档去跑“整理一段 300 字会议记录”这种简单活，效果看不出差别，积分却一下掉一大截。简单活选免费或快速档，写复杂代码、做大方案再切均衡或极致档，好钢用在刀刃上。
</Warning>

## 2. 积分从哪看、平时怎么领

点左下角头像，就能直接看到当前的 **套餐** 和 **积分余额**，下面这三个入口平时可以顺手点点：

- **Buddy加油站**：日常领免费积分的地方；
- **去邀约**：拉朋友体验也能拿积分奖励；
- **成长计划**：顺手完成一些新手/连登任务，还能领福利。

想看详细的每一笔消耗记录和积分到期时间，点进 **设置 → 套餐与积分** 就能查到。

## 3. 三个立竿见影的省积分习惯

1. **按任务轻重选模型**：润色、问答、简单整理用限时免费或快速档；复杂分析、写网页/小程序再换均衡或极致档。
2. **换一件新事，就点「新建任务」**：同一个对话聊得越长，AI 每次都要把前面所有聊天记录重新读一遍，越聊越费积分。一件事干完就开新对话。
3. **先问清楚再动手**：需求还没想明白时，先切到「仅问答 Ask」聊思路，比直接让它反复生成、推翻重来省得多。

## 顺带提一句：自定义模型

如果你手里本来就有其他平台的 API Key，模型列表最底部也支持点 **配置自定义模型** 接进来。但刚入门完全不需要折腾这个，先把内置模型和赠送积分用明白再说。

## 一句话记住

**日常练手选限时免费或快速档，复杂大活再切均衡/极致；换新事就开新任务，越聊越长越费积分。**
