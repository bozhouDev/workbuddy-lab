发任务前先确认一件事：**左下角「选择分组」选对了你的目标文件夹**（比如前面建好的 `WorkBuddy-练习`）。选好分组后，把资料喂给 WorkBuddy 主要有两种方式：

- **点左下角 `+` 号 → 添加文件**：既可以传电脑里的 **本地文件**，也能直接选 **资料库、腾讯文档、ima、乐享知识库** 里的资料（同时 `+` 菜单下面还能切模式、挑专家、挂技能和连接器）。
- **在输入框里直接打 `@`**：会弹出一个列表，可以精准点名引用当前分组里的文件或子文件夹（选好分组后，`+` 菜单里也会多出「引用对话中的文件」）。

## 两个小细节，能让它准很多

1. **文件名起明白点**：把文件叫 `项目背景.md`、`活动群聊记录.txt`，比叫 `文档1.docx`、`新建文本文档.txt` 好得多——AI 扫一眼文件名就知道这份资料是干嘛的。
2. **明确点名引用，别靠它翻目录碰运气**：文件就在当前分组里时，你不打 `@` 它有时确实会自己搜本地目录完成，但只要文件夹里文件一多、有新旧版本或同名记录，它很容易抓错旧版或把多份资料混在一起；如果文件根本不在当前分组（比如在桌面、下载目录，或腾讯文档 / ima 里），它搜目录更是搜不到，必须用 `+` 加进来。

## 一句话记住

**发任务前先选好分组；用 `+` 加外部资料、用 `@` 精准点名分组文件，文件名起得越清楚，它读得越准。**
