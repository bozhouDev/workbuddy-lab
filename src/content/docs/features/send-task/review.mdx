对话里出现“已完成”三个字，不代表活真的干对了。把 AI 当成一个干活很快的实习生，交出来的成果一定亲自看一遍。

## 养成习惯，至少核对这 5 眼

1. **右侧有没有产物**：文件卡片和右侧产物预览正常出来了吗？
2. **文件在不在目录里**：打开你电脑的分组文件夹，确认文件真的落盘了。
3. **能不能正常打开**：点开看排版有没有乱码、表格有没有错位。
4. **要求全满足了吗**：要的板块都在吗？原始文件没被误改吧？
5. **关键信息对不对**：人名、地点、金额、时间跟原文一致吗？比如在刚才的《周末读书会筹备纪要.md》待办表里，“印签到表桌签”的负责人和“拍照录像”的负责人/时间，它是不是老老实实标了 **「未明确」** 而没有自己乱填？

## 找不到生成的文件放哪了怎么办

按这个顺序依次查：

1. 看右侧 **产物预览区**；
2. 点对话下方的 **「查看所有产物」**；
3. 打开你选的 **分组文件夹**；
4. 翻一下对话里它自己写出的路径。

还是找不着，直接发一句：

```text
列出这次生成的所有文件名和完整路径
```

## 一句话记住

**看到“已完成”先别急着关：查产物区、查本地目录、查关键数字和「未明确」有没有被瞎补。**
