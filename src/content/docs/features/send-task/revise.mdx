第一版通常只是初稿，改一两轮再正常不过。但怎么提修改意见，直接决定了它是“一次改对”还是“越改越乱”。

## 二次修改的 3 条规矩

1. **就在当前这个对话里改，别开新任务**：它手里还攥着刚才的上下文和文件，接着改最稳、也最省事。
2. **千万别只说“不好看”“重做一版”**：你一说重做，它很容易把你本来已经满意的结构和文字全推翻。
3. **改的时候说清 4 件事**：**保留什么 + 改哪里 + 改成什么 + 哪些不能动**。

## 模糊说法 vs 具体说法

拿刚才那份《周末读书会筹备纪要.md》举例，把模糊话术换成具体指令：

- **模糊说法**：表格看着太乱了，帮我重新整理一下。
- **具体说法**：

```text
保留现有的四个板块和文字内容不要大改，只调整「待办事项表格」：
1. 按截止时间从近到远排序，没写截止时间的排到最后；
2. 把所有标注“未明确”的格子加粗，方便我一眼催人确认；
3. 直接更新《周末读书会筹备纪要.md》，别新建第二个文件。
```

如果这次改出来的格式你以后都想沿用，改完顺嘴补一句：“记住这个表格排序和加粗习惯，以后整理纪要都照这样来”——直接跟前面讲的 [记忆](/features/setup/memory/) 接上了。

<Warning title="干大活前的两条底线">
  <ul>
    <li><strong>重要文件先留备份</strong>：永远别拿唯一原件直接给 AI 练手。</li>
    <li><strong>大任务先拿小样本试水</strong>：比如要整理 200 个文件，先挑 5 个放进测试文件夹跑通一遍，确认套路和效果都满意了，再放全量。</li>
  </ul>

## 一句话记住

**在原对话里做局部修改，说清「保留什么 + 改哪里 + 改成什么」，改顺手了顺口让它记住。**
