输入框外面左下角、「选择分组」旁边就是 **权限**。点开里面有一个 **「允许完全访问」** 开关，决定 WorkBuddy 动你电脑文件时要不要先问你一声。

| 状态 | 权限范围 | 建议 |
|---|---|---|
| **默认权限**（开关关闭） | 在当前工作范围内正常干活；一旦涉及敏感目录、删除文件、运行系统命令，会先弹窗请你批准 | **新手一直保持这个就行** |
| **允许完全访问**（开关打开，变红） | 放开更多本地文件和命令权限，大幅减少确认弹窗 | 熟悉边界后、处理明确且可信的任务、且**提前做好备份**再用 |

<Warning title="别为了省两下点击长期开完全访问">
  万一你开着「允许完全访问」随口发一句“把没用的旧文件清理一下”，它顺手把你别的目录里的东西删了，哭都来不及。新手日常一直保持默认权限就够了。
</Warning>

## 弹出审批窗口时，别闭眼点「允许」

在默认权限下，AI 准备做高风险动作时会弹出一个确认窗，你花 3 秒看清三件事再决定点不点允许：

1. **它要做什么动作**：是读取、新建，还是覆盖、删除、跑一段命令行？
2. **目标路径对不对**：动的是不是你当前选的那个分组文件夹？一旦看到路径跑到了桌面、系统盘或者别的无关目录，果断拒绝。
3. **这一步是不是必需的**：比如你只是让它总结一篇文章，它却申请删除文件，明显不合理。

## 看不懂弹窗怎么办

要是弹窗里看不懂、或者拿不准要不要让它删，千万别硬着头皮点确认。直接选 **取消操作**，或者点底部的 **其他补充…**，把下面这句话发给它：

```text
请先用大白话解释一下，刚才那一步会动到哪些文件、为什么要执行？能不能先给我看个清单或预览？
```

## 一句话记住

**新手一直保持「默认权限」；弹出审批窗时先看动作、路径和必要性，拿不准就先取消再问清楚。**
