光看道理记不住，现在直接用前面的套路，在你的 `WorkBuddy-练习` 分组里跑通第一个完整小任务。

## 第 1 步：准备一份带“陷阱”的练习材料

在你的练习文件夹里新建一个叫 `周末读书会群聊.txt` 的文件，把下面这段假群聊复制进去（里面**故意有两件事没写负责人或截止时间**，正好拿来检验它会不会瞎编）：

```text
阿林：大家，周六下午两点的线下读书会场地已经定好了，在静安寺那家青松咖啡二楼包间。
小周：太好了！那海报我今晚下班前改完发群里给大家看。
阿林：行，另外现场签到表和桌签谁来印一下？最好周五中午前搞定。
老陈：茶歇和饮品我来订，预算控制在 500 块以内，明天下午确认好菜单。
小周：对了，周六现场谁负责拍照片和录像？回头要发公众号回顾的。
阿林：这个还没定人，回头再看。还有，开场 PPT 我周四晚上给初稿，大家周五上午提意见。
```

## 第 2 步：按 5 要素发任务

1. 左下角「选择分组」选中 `WorkBuddy-练习`，权限保持 **默认权限**，模型选限时免费的 `Hy4 flash` 或「快速」就够了。
2. 在输入框里用 `@` 引用 `周末读书会群聊.txt`，然后贴上下面这段指令发送：

```text
请读取 @周末读书会群聊.txt，整理成一份《周末读书会筹备纪要.md》，保存到当前分组文件夹里。

要求：
1. 内容包含：活动基本信息、已确定的事项、待办事项表格、仍需确认的问题。
2. 待办事项表格包含：具体事项、负责人、截止时间、备注。
3. 原记录里没写明的负责人或截止时间，一律标注“未明确”，严禁自己猜测补充。
4. 不要修改原始文件。
5. 完成后告诉我生成的文件名，并列出你认为最需要我核对的 3 处内容。
```

## 第 3 步：盯着执行过程，别瞎催

发出去之后，中间对话框会实时展示它在读文件、整理、写新文件：

- 它在跑的时候**不用反复发消息催它**，等它出结果就行；
- 如果画面半天卡着不动，先看一眼是不是弹出了**审批确认窗**在等你点允许；
- 如果真的卡死或明显跑偏，直接点停止按钮，把任务拆小一点（比如先处理单个文件）重来。

## 一句话记住

**执行时别反复催；画面长时间不动先查是不是在等你点审批，真卡住了就中止拆小重来。**
