通勤路上突然想起一件事，人不在电脑旁边，却想让家里的电脑先帮你查好资料、把初稿写出来——WorkBuddy 背靠腾讯生态，手机远程派活不需要折腾服务器或内网穿透，几分钟就能连上。

## 怎么把手机接进来（两种方式）

### 方式 1：直接用移动设备扫码连接（最快捷）

点 WorkBuddy 左下角头像旁边那个 **移动设备小图标**（也可以在「设置 → 设备连接」里找到），把底部的 **允许移动设备远程连接** 开关打开，直接扫码连上 **WorkBuddy 移动端 App** 或 **微信小程序**。

### 方式 2：接入聊天软件「助理」（像跟微信好友聊天一样派活）

点左侧栏 **助理（BETA）** 右边的小齿轮（或直接进 **设置 → 助理**），可以看到所有远程通道：**微信助理、微信客服号、企业微信机器人、QQ 机器人、飞书集成、钉钉机器人集成**，甚至还有专门接收定时任务结果的 **定时任务企微 bot 同步**。

个人新手最推荐直接连 **微信助理** 或 **微信客服号**，扫码绑定完就能直接在微信聊天窗口里派活、收结果。底部的 **上下文管理** 开关建议保持开启，长时间没说话会自动重置会话，帮你省积分。

## 搞清活在哪跑：云电脑 vs 本地电脑

手机上打开 WorkBuddy（以微信小程序为例），标题下面有一行小字 **☁ 云电脑 ›**。它说的是**这个活在哪台电脑上跑**。点它会弹出「**选择设备**」，里面两项：

- **云电脑**：腾讯云上的一台电脑。电脑版里的说明是「云端运行，关机不中断、多端同步接力；无法处理本地未上传的资料」。
- **你自己的电脑**：显示的是电脑名字（比如「某某的 MacBook Pro」），后面有绿色的「**在线**」才选得了。电脑版里叫「本地电脑」，说明是「本地运行，直接处理本机资料、操作当前电脑；需保持电脑在线」。

| 对比项 | 云电脑 | 本地电脑 |
|---|---|---|
| **活在哪跑** | 腾讯云上的电脑 | 你自己的电脑 |
| **电脑要开机吗** | **不用**，关机也不中断 | **必须开机且联网** |
| **能碰哪些文件** | 只能用上传到云端的资料 | 能直接读写你电脑里的文件和软件 |
| **适合什么场景** | 通勤、出差，查资料写文案 | 人在外头，想用家里/公司电脑上的资料干活 |

最常见的翻车：在云电脑上说「把我电脑里的 XX 文件发我」，它会告诉你访问不到。在「选择设备」里选你自己的电脑，再发一次就好。

## 别漏掉关键配合：打开「允许锁屏运行」

如果你打算让手机派的活在 **本地电脑** 上跑，一定记得回 **设置 → 通用**，点开 **允许锁屏运行**——里面有三档：**关闭 / 熄屏后保持唤醒 / 保持屏幕常亮**。

远程用推荐选中间那档 **「熄屏后保持唤醒」**（屏幕正常熄灭省电，但后台任务和远程控制照常跑），同时保持下面的「运行时防止系统休眠」开启。不然你人一出门、电脑一锁屏休眠，手机发过去的指令就断了。

<Warning title="手机遥控的两条安全建议">
  <ol>
    <li><strong>先拿只读和生成类小活练手</strong>：比如让它搜新闻摘要、查分组里某份方案写了哪几块、把语音灵感整理成大纲。</li>
    <li><strong>高风险操作尽量回电脑前再确认</strong>：手机屏幕小看不全路径细节，批量删文件、覆盖重要原件、往团队群发消息别在手机上盲点确认。</li>
  </ol>
</Warning>

## 一句话记住

**个人首选微信助理或扫码连小程序；需要远程动电脑本地文件时，记得在通用设置把「允许锁屏运行」调到「熄屏后保持唤醒」。**
