这一步很简单，只提醒两个容易踩的小坑：认准官网，以及 Mac 用户选对芯片版本。

## 1. 只从官网下载

在浏览器里打开 WorkBuddy 官网（`https://www.workbuddy.cn`），别去第三方软件站搜着下，省得顺手装上一堆流氓全家桶。

## 2. 选对系统版本（Mac 用户特别注意）

除了 Windows 和 Mac，官网现在也提供了鸿蒙电脑版、Linux 以及手机端/小程序。点「立即下载 WorkBuddy」时，右侧标着 **当前设备** 的就是系统自动帮你匹配的版本。

**Mac 用户下载前多看一眼芯片型号**：把鼠标移到 Mac 上会展开 **Mac Intel 芯片** 和 **Mac Apple 芯片** 两个选项，带绿点的通常是你当前电脑对应的版本。如果不放心，点屏幕最左上角的苹果图标 → **关于本机**，看一眼芯片是 Apple M 系列还是 Intel 就稳了，别下反了。

## 3. 安装与首次打开

下载完双击安装包，跟装微信、QQ 一样一路往下点就行。

## 一句话记住

**只从 `workbuddy.cn` 官网下载；Mac 用户下之前确认一眼是 Apple 芯片还是 Intel 芯片。**
