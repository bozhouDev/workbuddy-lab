功能篇把 WorkBuddy 的功能都摸了一遍，从这篇开始做真东西。

数据分析是职场里最容易被 AI 坑的场景。很多人把几张 Excel 直接往对话框里一扔，发一句「帮我分析一下这些数据并画图表」。AI 确实很快就能给你一份看起来头头是道的报告，但你一细核对：重复订单算了两遍、退单也算进了营收，甚至结论里蹦出来一个原表里根本算不出来的数字。

这一篇用一套还原职场痛点的案例，把 **「先体检定口径，再计算留公式，最后出交互看板」** 这套防翻车工作流一次跑透。

## 一、准备素材和开工设置

练习数据是一套虚构品牌「青松咖啡」2026 年四个季度的线上销售订单表，共 4 个 `.xlsx` 文件，约 300 条记录：

```text
实战1-数据分析/
├── 2026_Q1订单表.xlsx
├── 2026_Q2订单表.xlsx
├── 2026_Q3订单表.xlsx
└── 2026_Q4订单表.xlsx
```

**[下载练习表（4 个 Excel 打包）](/downloads/qingsong-coffee-2026-orders.zip)**，也可以在 GitHub 仓库的 `materials/sales-data/` 目录里找到。这 4 张表里**刻意埋了几类职场常见的脏数据**，正好用来测 WorkBuddy 的体检能力。

开工前做 3 件准备：

1. 在电脑里新建文件夹 `实战1-数据分析`，把 4 个 Excel 放进去，并在 WorkBuddy 左下角 **选择分组** 关联这个文件夹（忘了怎么弄，回看 [分组](/features/setup/groups/)）；
2. 权限保持 **默认权限**；模型建议选自动档 **均衡**，或者 `Hy4`、`GLM-5.3` 这类推理稳一点的模型（见 [模型与积分](/features/setup/models-credits/)）；先练手的话 `Hy4 flash` 也可以跑；
3. 召唤 **数据分析专家**：左侧「专家·技能·连接器」搜 `数据分析专家` 点召唤，或在输入框点 `+ → 专家`（回看 [专家](/features/extend/experts/)）。召唤专家之后，它看数据的视角会明显更像业务人员，不只停留在算个加减乘除。

## 二、第一轮：先体检、定口径，千万别急着画图

**数据分析防翻车的第一条铁律：第一轮只让 AI 看数据、挑毛病、报口径，不让它直接出最终图表。**

用 `@` 把 4 张季度表全部引用进来，或者直接让它查看当前目录下的四个订单表，发送第一轮提示词：

```text
看一下我当前目录下的 2026 年四个季度的订单表，对这四份先做一次全面的数据体检：
1. 检查并列出所有数据质量问题（包括但不限于：重复订单、缺失值、格式或命名不统一、退单/取消订单分布等），给出具体数量和示例订单号；
2. 列出你认为这份数据最值得分析的 4-5 个业务维度和关键指标；
3. 把需要和我确认的统计口径一条条列出来，等我确认后再进入下一步计算。

重要限制：这一轮只做「数据体检」，只用简明文字回复上面 3 点，严禁创建任何文件、不要清洗导出数据、不要生成图表，也不要提前做额外分析。
```

> **真机实测踩坑：一定要按住「数据分析专家」，让它只干这一件事！**
> 召唤专家之后，它自带一套很重的「全流程专业分析习惯」。如果不加最后那句硬限制，它往往会特别勤快：一边体检一边顺手做深度审计、写脚本，甚至直接把清洗文件都生成出来，一轮动不动跑很久，也多费积分。**发第一轮时把「只做体检、不生成任何文件、不干其他事」写死**（或者顺手打开 `计划 Plan` / `仅问答 Ask` 模式，见 [模式](/features/send-task/mode/)），就能拿到干脆的体检清单。

跑完这一轮，正常情况下它会把表里埋的脏数据全揪出来：

- **重复订单**：4 张表一共混了 5 条订单号完全相同的重复记录；
- **非成交订单**：混着 17 单「已退款」和 8 单「已取消」；
- **格式与命名不统一**：金额里混着 `¥79`、`211元` 这种带符号的文本（直接求和会被 Excel 跳过），渠道里把「小红书小店」简写成了「小红书」、「抖音直播间」写成了「抖音」，日期格式也不统一；
- **缺失值**：有 3 条已完成订单漏填了实付金额，2 条漏填了渠道。

> **如果不做这一步会怎样？** 跳过体检直接让它对 4 张表求和，原始纯数字加起来高达 **¥56,396**；把重复单、退单和取消单剔除、文本金额洗干净后，真正的有效净成交额是 **¥51,407**。不先定口径，光总营收就虚高了将近 10%。

<Shot src={imgRound1} alt="数据分析专家的第一轮体检结果，列出重复订单、缺失值等问题和具体订单号" caption="第一轮体检：列出问题、数量和示例订单号，不产出任何业务指标" />

看完体检报告，在同一个对话里明确回复你的 **统计口径**（告诉它每类问题怎么处理）：

```text
体检结果我确认了，接下来按以下口径统一清洗和统计：
1. 重复订单：按「订单号」去重，只保留 1 条；
2. 格式统一：金额去掉 ¥ 和“元”转成纯数字；日期统一成 YYYY-MM-DD；渠道名统一合并（「小红书」→「小红书小店」，「抖音」→「抖音直播间」，「小程序」→「微信小程序」）；
3. 缺失值处理：缺失金额的 3 条已完成订单，金额留空不自行估算，并在备注里单独标出「待核实」，不计入营收汇总；缺失渠道的 2 条归入「未标注渠道」；
4. 营收口径：只把状态为「已完成」且金额非空的订单计入有效净成交额；「已退款」和「已取消」单独统计退款率，不计入净成交额。
```

## 三、第二轮：清洗计算 + 多 Sheet 图表，把公式留在表里

口径定死了，再让它干重活。这一轮有两个硬要求：

- **绝不改原始 4 张表**，全部输出到一个新文件里；
- **汇总表和各维度分析表必须用 Excel 公式（如 `SUM`、`SUMIFS`、`COUNTIFS`）算出来，不要直接填死数字**。公式留在表里，你随时点一下单元格就能看到数字是从哪算出来的，彻底堵死 AI 编数字的可能。

在同一个对话里发第二轮提示词：

```text
请按刚才确认的口径，生成一份新的 Excel 文件《青松咖啡_2026年度销售分析.xlsx》保存到当前分组（不要修改原来的 4 份原始订单表）。

要求工作簿包含以下 Sheet：
1. 「清洗后明细」：合并 Q1-Q4 去重并规范格式后的全部订单，增加「季度」列和「数据备注」列（标出缺失金额/缺失渠道的待核实记录）；
2. 「年度总览」：展示全年有效净成交额、有效订单数、客单价、总退款率，以及按 Q1-Q4 拆分的季度趋势汇总表，配一张季度营收趋势折线/柱状图；
3. 「渠道分析」：按统一后的渠道统计各渠道订单数、有效净成交额、营收占比和分季度退款率，重点标出异常波动的渠道，配柱状图和占比图；
4. 「商品与城市分析」：统计各 SKU 的销量与销售额排行、以及各城市销售分布，配条形图。

关键硬要求：
- 所有汇总表的统计数字必须使用 Excel 动态公式（如 SUM、SUMIFS、COUNTIFS）引用「清洗后明细」表计算，严禁直接写死纯数字；
- 完成后给我一段简明的文字版核心业务发现（不超过 5 条），每条结论后面必须附带对应数字。
```

<Shot src={imgRound2} alt="左边是核心业务发现，右边是生成的多 Sheet 分析表" caption="第二轮：左边是带数字的业务发现，右边是生成的分析表" />

这一轮跑完，文字结论里就能看到几个扎实的业务发现（下一篇实战 2 做汇报 PPT 就用它们）：

- **全年稳步增长**：有效净成交额 **¥51,407**（272 单，客单价 ¥189.00），从 Q1 的 ¥9,995 一路涨到 Q4 的 ¥15,628（涨幅 56.4%）；
- **夏日爆款 + 冬季高客单**：全年销冠是「夏日冷萃液礼盒」（¥14,193，占 27.6%），单均实付最高的是 Q4 上新的「冬季限定肉桂拿铁礼盒」（¥274.10）；
- **揪出一个大异常**：天猫（37.0%）和抖音（27.9%）撑起超六成营收，但 **抖音直播间 Q3 退款率突然飙到 17.24%**（远超全年 5.67% 的平均水平），明显值得业务复盘；
- **城市与私域特征**：上海（25.3%）和北京（20.2%）合计占了近一半营收；微信小程序体量虽小，但全年 0 退款。

想直接对照结果，可以 **[下载这份分析表](/downloads/qingsong-coffee-2026-analysis.xlsx)**。

## 四、第三轮：生成可交互的 HTML 数据看板

Excel 适合留底和核对，但发给老板、客户或者开会投屏时，甩过去一个多 Sheet 表格，大家其实懒得点来点去。

让 WorkBuddy 基于刚才算好的数据，再出一份 **单文件可交互 HTML 看板**：双击就能在浏览器里打开，还能按季度、渠道筛选。

在同一个对话里发第三轮提示词：

```text
请严格基于《青松咖啡_2026年度销售分析.xlsx》里算出来的真实数据和结论，生成一个单文件的可交互 HTML 数据看板，命名为《青松咖啡_2026销售看板.html》保存到当前分组。

要求：
1. 风格干净、偏浅色商务风，像现代 BI 工具一样清爽易读，打开就能直接看重点，不要花哨炫技；
2. 顶部放 4 张核心 KPI 卡片（全年有效净成交额、有效订单数、平均客单价、整体退款率）；
3. 支持按「季度（全部 / Q1 / Q2 / Q3 / Q4）」和「渠道」交互筛选，切换筛选条件时，上方 KPI 和下方图表要同步联动变化；
4. 页面包含 4 个核心图表：季度营收趋势图、各渠道营收与占比对比、各渠道分季度退款率异常监控（高亮 Q3 抖音退款率异常）、商品销售额 Top5 排行；
5. 页面底部放「关键业务洞察」和「数据清洗口径说明」两个卡片，把待核实的 3 条缺失金额订单也透明标出来；
6. 所有数字必须 100% 与 Excel 一致，严禁自己估算或编造任何新数字；图表库用稳定可访问的 CDN 或内置 SVG/Canvas，确保本地直接双击 HTML 就能正常渲染不白屏。
```

### 生成完怎么打开、怎么发给别人？

- **自己看**：在 WorkBuddy 右侧产物预览区就能直接点开交互；也可以去分组文件夹里找到 `青松咖啡_2026销售看板.html`，**双击用浏览器打开**。
- **发给老板或同事**：单文件 HTML 不需要装软件、也不用搭服务器，**直接把这一个 `.html` 文件发微信或飞书给对方**，对方点开就能看、能筛选。

## 五、抽查核对与二次修改（别省这一步）

看板做得再好看，数字错了全白搭。发给别人之前，花 2 分钟做完两件事。

### 1. 抽查 3 个数，防 AI 编数字

不用每行重算，挑 3 个关键数字，拿 HTML 看板和 Excel 里的公式结果逐一核对：

- **全年有效净成交额**：是不是精确等于 `¥51,407`、272 单，有没有把重复单或退单算进去；
- **某一个季度的销售额**：比如筛选 Q3，看是不是精确跳成 `¥13,241` / 69 单，和 Excel 年度总览一分不差；
- **Q3 抖音直播间的退款率**：筛选「Q3 + 抖音直播间」，看是不是显示 `17.24%`。

### 2. 发现小毛病怎么改？

第一次生成偶尔会碰到小毛病：筛选器点完某个图表没联动、文字挤在一起、配色太花。

二次修改的原则（见 [修改](/features/send-task/revise/)）：**在同一个对话里改，一次说清具体改哪里，别说「重做一版」。** 例如：

```text
整体布局和数据都保留不要动，只修改下面两处：
1. 切换顶部「季度」筛选按钮时，商品排行柱状图的数据没有跟着刷新，请修好联动逻辑；
2. 「各渠道分季度退款率」折线图里，把 Q3 抖音直播间那个数据点标成醒目的红色圆点，并直接显示具体百分比标签。
```

> **这次真机实测的两条经验**
> 1. **第一轮一定要按住专家「只干一件事」**：「数据分析专家」非常敬业，不明确要求它第一轮只输出文字清单，它会自己跑一大堆额外校验，甚至提前生成中间文件，耗时变长也多耗积分；加上「只做体检、不写文件」后节奏舒服很多。
> 2. **看板优先要求「单文件、零外部依赖」**：这次生成的看板用内联 SVG 画图，把清洗后的数据内嵌进文件里，不依赖任何外部网络资源，断网双击也能打开，发给别人最省心。

## 顺手提一句自动化

如果你每个月都要处理同一套格式的销售表、运营表，把上面三轮提示词理顺、**手动跑满意 2～3 次之后**，可以接上 [定时任务](/features/automation/schedule/)，让它每月固定时间去指定文件夹读新表，自动更新月报和看板。
